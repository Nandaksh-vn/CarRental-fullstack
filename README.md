# 🚗 Car Rental Full Stack Application

A full-stack web application that allows users to browse, book, and manage car rentals online. This system provides an intuitive interface for customers and an admin panel for managing vehicles, bookings, and users.

---

## 📌 Features

### 👤 User Features

* View available cars
* Search cars by category, price, or availability
* Book a car for specific dates
* View booking history
* User authentication (Login/Register)

### 🛠️ Admin Features

* Add, update, and delete cars
* Manage bookings
* View registered users
* Dashboard with rental insights

---

## 🏗️ Tech Stack

### Frontend

* React.js
* HTML5, CSS3
* JavaScript (ES6+)

### Backend

* Node.js
* Express.js

### Database

* MongoDB

### Other Tools

* Axios (API calls)
* JWT (Authentication)
* Git & GitHub (Version control)

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```
git clone https://github.com/your-username/CarRental-fullstack.git
cd CarRental-fullstack
```

### 2️⃣ Setup Backend

```
cd backend
npm install
npm start
```

### 3️⃣ Setup Frontend

```
cd frontend
npm install
npm run dev
```

---

## 🔐 Environment Variables

Create a `.env` file in the backend folder and add:

```
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

---

## 🚀 Usage

* Open browser and go to:
  `http://localhost:3000` (or Vite default port)

* Register/Login as user

* Browse cars and make bookings

* Admin can manage system via dashboard
